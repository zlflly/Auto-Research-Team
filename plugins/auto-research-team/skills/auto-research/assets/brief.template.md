# Task brief

## Goal and deliverable
Source request / relevant codebase / requested output.

## Fixed constraints
Only explicit user constraints, interfaces or accepted mathematical invariants.

## Insights
Each entry: source/line or message, faithful statement, constraint vs hypothesis, mechanism, falsification evidence. Include unconfirmed oral insight as user-provided hypothesis, not a fact.

## Scope and authorization
Writable files/workspaces; read-only evaluation/data; existing user changes to preserve; approved resources and side effects. State what needs escalation.

## Acceptance protocol
Engineering: required behavior and regression checks.
Algorithm: baseline, metric direction, minimum meaningful effect, data/split protocol, resource comparability, confirmation procedure, claim scope.
Theory: explicit proof obligations and remaining gaps, where applicable.

## Allocation and termination
Actual agent concurrency cap; candidate branches; managed runs/time; GPU job allocation; debug/review limits; confirmation reserve; completion/no_gain/inconclusive criteria.

## Decision policy
Scope/metric/budget changes and unresolved evidence conflicts go to user. Reversible implementation choices and within-contract branch selection stay with Owner.
